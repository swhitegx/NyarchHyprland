# Changes

Here are listed all the main changes done to EzArcher template, in order to adapt it for the Hyprland spin.

- [ ] Added Hyprland and Wayland base packages
- [ ] Added Waybar, Wofi, Dunst, and other Hyprland utilities
- [ ] Added SDDM as display manager
- [ ] Replaced GNOME-specific packages with Hyprland equivalents
- [ ] Set SDDM as default display manager in steps.sh
- [ ] Calamares displaymanager config set to SDDM
- [ ] Added end-4/dots-hyprland inspired dotfile structure
- [ ] Changed Plymouth theme for Hyprland spin
- [ ] Added pipewire audio setup
- [ ] Added XWayland support
